# 🎮 Tic-Tac-Toe AI

## 📌 Project Overview

Tic-Tac-Toe AI is an interactive web-based game developed using **Python** and **Streamlit**. The project allows a user to play Tic-Tac-Toe against an AI opponent.

The AI uses the **Minimax algorithm** to analyze possible moves and choose the best available move.

This project demonstrates basic concepts of **Artificial Intelligence, game logic, decision making, recursion, and web application development using Streamlit**.
live demo:https://tic-tac-toe-ai-zr4zuhjgizzhwtv5h4gx26.streamlit.app/
---

## 🎯 Project Objective

The main objective of this project is to develop an interactive Tic-Tac-Toe game where:

* The user can play against an AI.
* The AI can analyze the current game state.
* The AI selects an optimal move using the Minimax algorithm.
* The game provides an easy-to-use web interface.
* The project demonstrates a simple practical application of Artificial Intelligence.

# ⚙️ Installation Process

Follow the steps below to run the project on your computer.

## Step 1: Install Python

First, install Python on your computer.

After installation, open **Command Prompt** and check whether Python is installed:

```bash
python --version
```

If Python is installed correctly, you will see the Python version.

---

## Step 2: Create a Project Folder

Create a folder on your computer named:

```text
Tic-Tac-Toe-AI
```

Open the folder.

---

## Step 3: Create the Python File

Inside the project folder, create a file named:

```text
app.py
```

Paste the complete Tic-Tac-Toe Python code into this file.

---

## Step 4: Create requirements.txt

Create another file inside the same folder:

```text
requirements.txt
```

Add:

stream lit
```

Save the file.

---

## Step 5: Open Command Prompt in the Project Folder

Open the `Tic-Tac-Toe-AI` folder.

Click the folder address bar and type:

```text
cmd
```

Then press **Enter**.

Command Prompt will open directly inside your project folder.

---

## Step 6: Install Streamlit

Run:

```bash
pip install streamlit
```

Wait until the installation is completed.

---

## Step 7: Run the Project

Run the following command:

```bash
streamlit run app.py
```

Streamlit will start the application.

A browser window will open automatically with the Tic-Tac-Toe game.

If it does not open automatically, Command Prompt will provide a local URL. Open that URL in your browser.

# 🎮 How to Play

## Step 1

Open the Tic-Tac-Toe application in your browser.

## Step 2

The game board will be displayed.

## Step 3

Select an empty position on the board.

## Step 4

Your move will be registered.

## Step 5

The AI will analyze the available moves.

## Step 6

The AI will select its move using the Minimax algorithm.

## Step 7

The game continues until:

* You win 🏆
* AI wins 🤖
* The game ends in a draw 🤝

## Step 8

Start a new game using the restart/new-game option provided in the application.

# 🧠 How the AI Works

The project uses the **Minimax algorithm**.

Minimax is a decision-making algorithm commonly used in two-player games.

The AI considers possible future moves and evaluates the game states.

### Basic Process

```text
Current Game Board
        ↓
Check Available Moves
        ↓
Generate Possible Moves
        ↓
Evaluate Future Game States
        ↓
Minimax Algorithm
        ↓
Select Best Move
        ↓
AI Makes Move
```

The AI tries to maximize its chances of winning while minimizing the possibility of losing.
